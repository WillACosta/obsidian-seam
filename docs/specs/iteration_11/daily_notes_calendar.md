# Daily Notes calendar in the Universal Palette

- Add the standalone `@calendar` special query. Keep visible `@today`, `@yesterday`, and `@calendar` entries adjacent in that order, anchored at the first daily entry in the existing sorted list. Hidden entries remain hidden; custom searches remain available.
- Use the supplied calendar image and [Obsidian Calendar plugin](https://github.com/liamcain/obsidian-calendar-plugin) as inspiration. Build with public Obsidian APIs, without requiring the Calendar plugin or copying its weekly-note or word-count features.
- Display a localized month/year header, previous/next controls, Today, weekday labels, and six weeks of dates. Dim adjacent-month dates, mark today, highlight the selected date, and place one dot under dates with a Daily Note. Look up configured paths directly, without reading note contents to draw the calendar.
- Follow core Daily Notes folder, date format (including nested paths), and template. Initially select the open Daily Note's date, or today if the current note is not a Daily Note. Use the Obsidian language's week start.
- Clicking an existing date opens its note. Clicking a missing date selects it and offers an explicit Create daily note button. Enter creates the selected missing date or opens its existing note. Never overwrite a concurrent note or an occupied folder; show errors without closing the calendar.
- Keep the Palette input editable. Up/Down enters calendar navigation; Left/Right moves one day and Up/Down one week. Home/End selects the start/end of the week. Page Up/Down changes months; Shift+Page Up/Down changes years.
- Clicking the month/year header opens a twelve-year picker; choosing a year opens a twelve-month picker, and choosing a month returns to dates. Previous/next shifts the displayed period. All toolbar controls are reachable with Tab and activated with Enter/Space. Picker cells support arrows (three columns), Enter/Space, and Page Up/Down.
- Use a dedicated public Obsidian keyboard scope while focus is inside the calendar. Escape once returns to the input and leaves the calendar open; Escape again from the input dismisses the Palette. Tab can leave calendar navigation without trapping focus.
- Footer: navigate, open or create according to the selected date, dismiss. While choosing a year/month, replace open/create with select.
- English and Brazilian Portuguese copy, theme variables, narrow-window scrolling/wrapping, live note existence updates, and loading/error/retry states are required. Closing, changing query, or unloading the plugin must dispose keyboard scopes, events, and calendar DOM, and discard late settings reads.
