# Confirm periodic-note creation

Source: user request, 2026-10-26.

- Add “Ask before creating periodic notes” under Calendar and periodic notes, enabled by default for new and existing installations.
- Confirm before Seam creates daily, weekly, or yearly notes through date queries, calendar daily/weekly actions, rolling weekly pins, and daily-task transfer to a missing destination.
- Identify the exact target path; provide Create note and Cancel. Escape, outside dismissal, and Cancel must not create notes or folders, move tasks, or open a new destination.
- Existing notes open directly. Disabling the option restores direct creation. Preserve configured folders, templates, conflict protection, anchored dates, and requested current/tab/split routing after acceptance.
