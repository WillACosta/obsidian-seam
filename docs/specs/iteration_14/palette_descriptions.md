# Palette Descriptions

## Settings

- Remove the description visibility toggle from the Special Search settings group.
- Add **Show commands and special queries descriptions** to the Universal Palette settings group.
- The setting defaults to enabled and controls descriptions for Palette commands and built-in or custom special queries.
- Existing installations retain their previous description visibility preference.

## Custom search descriptions

- The New/Edit custom search modal provides an optional description text input.
- Save and preserve the description when a custom search is edited or duplicated.
- When present, show the custom description under its query in the Universal Palette while descriptions are enabled.
- When empty, retain the existing mode-specific query detail as the displayed description.
- The shared Universal Palette description setting hides and shows custom descriptions together with command and built-in query descriptions.
