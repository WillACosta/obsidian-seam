# Calendar Note-Opening Shortcuts

- In `@calendar`, Enter opens the selected daily note in the existing pane; Mod+Enter opens it in a new tab, and Shift+Enter opens it in a vertical split. Mod+Shift+Enter also opens a split. Use Cmd on macOS and Ctrl elsewhere.
- Support the search input, date cells, daily/weekly action buttons, and pinned-note buttons. Preserve the destination through missing-note creation and confirmation; cancelling creates no note, tab, or split.
- Keep ordinary Enter/Space behavior on calendar controls and month/year pickers. Modified Enter must not choose periods, pin, or unpin notes.
- Display contextual footer shortcuts for the focused open/create action. Use “create in a new tab” / “create in split view” for missing notes, and “open in a new tab” / “open in split view” for existing notes. Hide opening shortcuts when period/pin controls are focused.
- While navigating the calendar, describe Escape as returning to search. From the search input, Escape dismisses the Palette. Preserve arrow navigation, IME input, and modified caret movement in the search field.
