# Universal Palette controls and pinned queries

- The X button dismisses the Universal Palette, including when the input is empty or contains chips or a special query. It is a labeled button, supports click, Enter, and Space, and releases its keyboard scope on blur or dismissal.
- Pinned built-in and custom special queries appear before every unpinned query in the `@` listing. Keep date queries together within each pin section, preserving configured ordering for other queries.
- Settings changes refresh an already-open special-query listing.
- Allow up to five pinned special queries in total, shared by built-in and custom queries. Apply the same limit when toggling pins or saving a custom query, and explain the limit in English and Portuguese.
- Calendar note pins retain their separate three-note limit.

- Press unmodified Backspace immediately after any active `@` query (including its trailing separator) to remove the whole token. Support calendar, built-in, custom/Base, date-range, and combined queries. Remove one query at a time and preserve remaining text, directories, and tag filters. Keep normal text editing, selections, modifier shortcuts, and composition intact.
