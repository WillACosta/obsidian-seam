## Remove itens after archive

The main idea here is to keep the system minimal and hussle-free. So we should provide an option to remove certain tags or properties when a tag is archived by the automation system.

Add in the plugin's options a new option for:

"Remove tags and properties after archiving a note"

As default we remove these if they exists after the archiving process: "#permanent", "#todo", "status" (property).

The user should have total control of what is removed after the archivation, so the default values can be revoked at any moment in the plugin's options.
